# docs/

Especificações por feature — cada feature vai em `docs/spec/[slug]/` com:

- `prd.md` — Product Requirements Document (o quê e por quê)
- `techspec.md` — Tech Spec (como implementar)
- `tasks.md` + `[num]_task.md` — tarefas de implementação
- `bugs.md` — bugs conhecidos

Nenhuma `docs/spec/[slug]/` real gerada ainda — sistema recém-instanciado.
